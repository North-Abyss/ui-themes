What are Universal Theme Tokens? expand_more
They are a standardized set of 30+ CSS custom properties that completely define an interface's typography, palette, depth, elevation, radii, and backdrops with zero JS overhead.
Can I download standalone themes? expand_more
Yes! Click the Download CSS button in the top toolbar to instantly grab a clean, single-file stylesheet for whichever theme is currently active.
How does the Palette Swapper work? expand_more
The palette swapper re-maps the color variables (such as Linear, Stripe, Supabase, or Resurrect-64) without breaking the surface physics (shadows, blur, borders, and bevels) of the active morphism.

1-Line CDN Quick Start

Zero Dependencies

Drop all 34 theme presets and design token primitives into any web project, HTML page, or framework with zero build tools:

<!-- 1. Include Universal Theme Engine via CDN -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/North-Abyss/ui-themes@main/dist/universal-themes.min.css">

<!-- 2. Activate any of the 34 themes -->
<html data-theme="material3">
Works in Vanilla HTML, React, Vue, Svelte, Astro, Angular, and Next.js.
