1-Line CDN Quick Start

Zero Dependencies

Drop all 22 theme presets and design token primitives into any web project, HTML page, or framework with zero build tools:

<!-- 1. Include Universal Theme Engine via CDN -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/North-Abyss/ui-themes@main/dist/universal-themes.min.css">

<!-- 2. Activate any of the 22 themes -->
<html data-theme="material3">
Works in Vanilla HTML, React, Vue, Svelte, Astro, Angular, and Next.js.
